# План: 175 мини-игр по жанрам

## Что есть в проекте

- Вся игра — один файл `index.html` на чистом JavaScript, без сборщика и сервера. Картинки — в `img`, с запасной загрузкой из сети.
- Сохранение: `localStorage`, внутри Telegram дополнительно облако Telegram (CloudStorage).
- Telegram Mini App подключён: ник и фото из профиля, цвета шапки, вибрация, облако.
- Уже работают: баланс в рублях, доход за клик, уровни и рамки аватара, энергия, кейсы с играми (6 редкостей), скины и рынок, 40 старых механик мини-игр.

## Принятые решения

| Вопрос | Решение |
|---|---|
| Объём | По этапам: каркас и 14 пилотных игр, дальше партиями по 10–15 |
| Старые мини-игры | Заменяются: игра библиотеки получает мини-игру своего жанра |
| Где код | Всё в одном `index.html` |
| Баланс энергии и шансов | Не меняется: только плашка энергии и кнопка «Шансы» |

## Как устроено

- **Жанр = кейс.** Семь жанров из задачи совпадают с семью кейсами: Шутеры, Выживание, Экшен, Инди, Хоррор, RPG, Стратегии.
- **Слот = номер игры в кейсе** (1–25). Игра библиотеки получает мини-игру своего слота. Мифический кейс берёт игры по кругу из всех жанров.
- **Реестр** `MG` в `index.html`: функция `reg(жанр, слот, название, цель, управление, фабрика)`. Пока слот не написан, у игры остаётся старая механика.
- **Интерфейс игры** — фабрика `(st, C)`, которая возвращает `dur`, `down`, `move`, `up`, `swipe`, `key`, `update`, `draw`, `factor`, `label`. Это тот же смысл, что `MiniGame` из задачи, но на обычном JS.
- **Общий хост** `startMini` даёт всем играм: отсчёт перед стартом, таймер, счёт, жизни, экран результата, награду, паузу, чёткую графику на экранах высокой плотности, единый ввод (нажатие, движение, отпускание, свайп).
- **Телефон.** Поле логическое, 720×360. В альбомной ориентации оно занимает весь экран, в портретной — поворачивается на 90°, координаты касаний пересчитываются.

## Что из задачи невозможно без сервера

- Проверка наград и розыгрыш кейсов на сервере, энергия по серверному времени.
- Публичная страница чужого инвентаря по ссылке `startapp=inv_<id>`.
- `shareMessage` через бота (нужен токен и серверная часть).

Вместо этого: локальное сохранение и облако Telegram, шеринг картинкой и ссылкой.
